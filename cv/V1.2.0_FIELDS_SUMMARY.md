# Soccer CV Pipeline v1.2.0 - New Fields Summary

## Overview

Version 1.2.0 adds comprehensive match metrics to `player_match_stats` for professional-grade soccer analytics. All existing field names remain unchanged; only new fields were added.

## New Fields in `player_match_stats`

### Speed Metrics
- **`top_speed_kmh`** (float, km/h): Maximum sustained speed in kilometers per hour
  - Complements existing `top_speed_mph`
  - Conversion: `top_speed_mph × 1.60934`

### Temporal Metrics
- **`minutes_played`** (float, minutes): Time from first to last visible frame
  - Calculated as: `(last_timestamp - first_timestamp) / 60`
  
- **`visible_minutes`** (float, minutes): Total time player was actually tracked
  - Calculated as: `frame_count / fps / 60`
  
- **`coverage_pct`** (float, %): Percentage of video frames in which player was tracked
  - Calculated as: `(tracked_frames / total_video_frames) × 100`

### Distance Efficiency
- **`distance_per_min_m`** (float, m/min): Distance covered per visible minute
  - Calculated as: `(distance_km × 1000) / visible_minutes`
  - Useful for comparing workload intensity across players with different playing time

### Spatial Position
- **`avg_pitch_x`** (float, meters): Average X position on pitch (0-105m)
- **`avg_pitch_y`** (float, meters): Average Y position on pitch (0-68m)
  - Indicates player's average field position during the match

### High-Intensity Efforts
- **`hsr_count`** (int): Number of high-speed running bursts ≥1 second
  - Threshold: ≥19.8 km/h (GPS standard)
  - Uses hysteresis (90% exit threshold) and dwell time (≥1s)
  
- **`hi_efforts_count`** (int): Total high-intensity efforts
  - Calculated as: `hsr_count + sprint_count`

### Speed Zone Distances

All zones use configurable thresholds (km/h), stored in `meta.json`:

- **`zone_walk_km`** (float, km): Distance in walk zone (0-7 km/h)
- **`zone_jog_km`** (float, km): Distance in jog zone (7-15 km/h)
- **`zone_run_km`** (float, km): Distance in run zone (15-20 km/h)
- **`zone_hsr_km`** (float, km): Distance in HSR zone (20-25 km/h)
- **`zone_sprint_km`** (float, km): Distance in sprint zone (≥25 km/h)

**Implementation notes**:
- Distance calculated using midpoint speed for each zone
- Zone edges configurable via `Config` class
- Zone boundaries written to `meta.json` for backend reference

### Acceleration Estimates

- **`accel_count_high`** (int): High acceleration events (≥3 m/s² for ≥0.7s)
- **`decel_count_high`** (int): High deceleration events (≤-3 m/s² for ≥0.7s)

**Implementation notes**:
- Uses smoothed velocity differentiation
- Dwell threshold: ≥0.7 seconds
- **Labeled as estimates** in documentation
- Subject to detection noise and frame rate limitations

## New Output File: `heatmaps.json`

Separate file to keep stats rows flat while providing spatial density visualization:

```json
{
  "1": [
    [0.0, 0.33, 1.2, ...],  // 21 columns (X: 0-105m, 5m cells)
    [0.5, 2.1, 3.4, ...],
    ...                      // 14 rows (Y: 0-68m, ~4.857m cells)
  ],
  "2": [...],
  ...
}
```

**Structure**:
- Keys: Track IDs (as strings)
- Values: 2D arrays `[14 rows × 21 columns]`
- Cell values: Time spent in cell (seconds)
- Grid covers 105m × 68m pitch
- Only generated when calibration is available

## New `meta.json` Fields

- **`zone_edges_kmh`** (object): Speed zone boundaries
  ```json
  {
    "walk": 7.0,
    "jog": 15.0,
    "run": 20.0,
    "hsr": 25.0
  }
  ```

## Null Handling (No Calibration)

When no pitch calibration is available, **all** physical metrics are set to `null`:
- All speed metrics (`top_speed_mph`, `top_speed_kmh`)
- All distance metrics (`distance_km`, `zone_*_km`, etc.)
- All position metrics (`avg_pitch_x`, `avg_pitch_y`)
- All temporal metrics (`minutes_played`, `visible_minutes`, `coverage_pct`)
- All count metrics (`hsr_count`, `sprint_count`, `hi_efforts_count`, `accel_count_high`, `decel_count_high`)

Only non-physical fields remain populated: `track_id`, `jersey_number`, `team`, `role`, `injury_risk`.

## Testing

All new metrics have unit tests in `cv/tests/test_metrics.py`:
- `test_speed_zones_synthetic`: Validates zone distance calculations
- `test_temporal_metrics`: Validates minutes_played, visible_minutes, coverage_pct
- `test_spatial_metrics`: Validates avg_pitch_x, avg_pitch_y
- `test_hsr_and_sprint_counts`: Validates burst counts with dwell threshold
- `test_acceleration_events`: Validates accel/decel event detection
- `test_heatmap_grid`: Validates 21×14 grid generation
- `test_null_metrics_without_calibration`: Validates all fields present even without calibration

### Loading Data

```python
import pandas as pd
import json

# Load player stats CSV
df = pd.read_csv('player_match_stats.csv')

# Load heatmaps (optional, for visualization)
with open('heatmaps.json', 'r') as f:
    heatmaps = json.load(f)

# Load zone boundaries from meta
with open('meta.json', 'r') as f:
    meta = json.load(f)
    zone_edges = meta['zone_edges_kmh']  # {'walk': 7.0, 'jog': 15.0, ...}
```

### Field Descriptions for Frontend

| Field | Unit | Description |
|-------|------|-------------|
| `top_speed_kmh` | km/h | Maximum sustained speed (rolling 1s window) |
| `minutes_played` | min | Time from first to last appearance |
| `visible_minutes` | min | Actual tracked time (may be less due to occlusions) |
| `distance_per_min_m` | m/min | Running efficiency (higher = more intense) |
| `avg_pitch_x` | m | Average field position (length) |
| `avg_pitch_y` | m | Average field position (width) |
| `hsr_count` | - | High-speed running bursts (≥19.8 km/h for ≥1s) |
| `sprint_count` | - | Sprint bursts (≥25.2 km/h for ≥1s) |
| `hi_efforts_count` | - | Total high-intensity efforts |
| `zone_walk_km` | km | Walking distance (0-7 km/h) |
| `zone_jog_km` | km | Jogging distance (7-15 km/h) |
| `zone_run_km` | km | Running distance (15-20 km/h) |
| `zone_hsr_km` | km | High-speed running distance (20-25 km/h) |
| `zone_sprint_km` | km | Sprinting distance (≥25 km/h) |
| `accel_count_high` | - | High acceleration events (estimate) |
| `decel_count_high` | - | High deceleration events (estimate) |
| `coverage_pct` | % | Percentage of match tracked |
